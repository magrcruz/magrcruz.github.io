## 📂 Repository Structure

* `_pages/` — Core pages: Home/Bio (`about.md`) and Experience (`experience.md`).
* `_publications/` — Research papers, posters, and journal articles.
* `_portfolio/` — Highlighted projects and undergraduate thesis.
* `files/` — Downloadable PDFs, slide decks, and BibTeX citations (`.bib`).
* `images/` — Media assets, teasers, and profile photos.
* `_data/navigation.yml` — Top navigation bar settings (Bio, Papers, Experience, Projects).
* `_config.yml` — Global website configuration, sidebar metadata, and social links.

## 💻 Local Development

To run and preview the site locally:

1. **Install dependencies:**
   ```bash
   bundle install
   ```

2. **Run Jekyll with live reload:**
   ```bash
   bundle exec jekyll serve --livereload
   ```

3. Open your browser at `http://localhost:4000/`.

*(Note: Whenever you make changes to `_config.yml`, restart the local server to apply them).*
